# Publication Notice

This repository is a portfolio presentation of the master's thesis work completed by Muhammad Kazim at Christian-Albrechts-Universitaet zu Kiel.

The CST figures and numerical results were extracted from the author's thesis. The thesis PDF is not redistributed because the supplied version contains unfinished placeholder text in its conclusion chapter.

The original CST project files and raw S-parameter exports were not available when this repository was prepared. The included Python code independently reproduces analytical cavity-frequency calculations and reported Q-factor comparisons; it is not a replacement for the CST electromagnetic model.
